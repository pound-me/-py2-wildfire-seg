# FLAME3 Smoke 人工标注小集合规划

日期：2026-07-30  
状态：仅规划，不打开测试图像、不开始标注  
前提：最终网络结构、训练协议和 checkpoint 选择规则冻结后执行

## 1. 规模与样本

当前预注册测试集共 107 张，小于“≤150 张”的预算：

- Fire 文件夹：89 张；
- No Fire 纯背景：18 张。

因此最终阶段优先对全部 107 张测试图进行 Smoke 标注，不再根据模型输出挑选样本，避免只标困难样本或优势样本造成选择偏差。测试集继续封存；在最终模型冻结前只保存本规划，不浏览图片、不生成模型测试预测。

## 2. 标注形式

- 单独保存二值 Smoke mask：0=非烟雾、1=烟雾、255=无法判断/边界忽略。
- 不把云、雾、曝光、树冠、热反光当成 Smoke。
- 可见火焰和高温火区不标为 Smoke；烟火混合且无法可靠分界的区域标为255。
- 烟雾半透明边缘允许2–3像素不确定带，避免强迫标注不存在的精确物理边界。
- 18张 No Fire 图片按用户确认应为空 Smoke mask；若人工发现例外，必须记录为数据语义异常，不能静默修正类别。

## 3. 与温度火区标签合成

最终三分类评估标签按以下优先级只读合成：

1. 温度伪标签的255边界和人工 Smoke 的255区域保持255；
2. 温度支持的活动火区设为 Fire；
3. 其余人工 Smoke 区域设为 Smoke；
4. No Fire 图片及其余确定区域设为 Background。

论文中必须称为“温度支持的活动火区伪真值 + 人工 Smoke 标注”，不能称为完全人工三分类真值。

## 4. 质量控制

- 随机抽取20张进行双人复标：15张 Fire、5张 No Fire。
- 报告双标 Smoke IoU、边界F1和争议像素比例。
- 争议样本由统一规则复核；不得参考待评估模型预测修改标签。
- 标注工具、规则版本、人员、时间和文件哈希全部保存。

## 5. 用途边界

- 该107张集合只用于最终冻结模型的一次测试评估。
- 不用于结构选择、损失权重选择、温度阈值修订或 checkpoint 选择。
- 若需要 Smoke 训练监督，必须另建训练/验证标注计划，不能挪用或提前查看这107张测试标签。
