# FLAME3 设备与物理 Batch 决策

日期：2026-07-30  
状态：用户批准，立即生效  
适用实验：所有 `flame3_*` 实验

## 1. 输入分辨率

- FLAME3 正式训练采用数据集原生配准分辨率：宽 `640`、高 `512`；
- 不沿用 FLAME2 的 `256×256` 正式训练协议；
- 配置文件中的宽高字段顺序必须通过单批次尺寸断言确认后再冻结，禁止仅凭字段名猜测；
- RGB、Celsius TIFF、伪标签和未来烟雾标签始终执行同一组几何变换。

## 2. 设备分工

- RTX 4070：承担第⑥步起的全部正式训练，包括30轮筛选、100轮正式训练、
  主要消融与论文主表seed；
- RTX 2060：只承担冻结模型零样本评估、单批次/短管线工程检查和最终同会话
  FPS/延迟测量；
- 禁止在2060与4070之间拆分同一组正式对比实验；
- 禁止将2060和4070组成异构同步多卡训练；
- 配准审计、温度伪标注和数据划分主要使用CPU，不受4070离线影响。

## 3. 物理 Batch 预注册

- `batch=4` 是4070上线后的首选候选；
- 4070上线后，先用最终计划中最占显存的已授权候选结构执行只看显存、OOM、
  AMP稳定性和吞吐的工程检查；不得查看或比较验证精度；
- 若物理batch 4在所有计划对比模型上稳定运行，则正式冻结为 `BATCHSIZE=4`；
- 若batch 4不能共同稳定运行，则在任何30轮精度结果产生前，选择所有对比模型
  都能稳定运行的同一个物理batch，并写计划修订；
- 一旦冻结，Fusion基线、ABL、SAMF、ABL+SAMF及后续获批候选必须使用相同物理
  batch；不得仅靠梯度累积宣称BatchNorm条件等价；
- 学习率、梯度累积和BatchNorm策略随最终物理batch一并预注册。

## 4. 速度与可比性

- 正式训练GPU型号和软件环境逐次保存；
- 精度对比只比较同一4070训练协议下的结果；
- 部署速度仍在RTX 2060上，以同一会话、相同输入、相同AMP设置、相同预热和
  计时次数成对测量；
- 实时门槛维持 `>=30 FPS`，不使用4070速度替代2060部署指标。

## 5. 当前执行状态

- 4070离线期间不启动FLAME3正式30轮或100轮训练；
- 继续执行配准归档、温度伪标注、时间块划分、2060零样本评估及烟雾小集合规划；
- 4070上线后先完成本文件第3节的batch工程检查，再创建正式训练配置。
