## 2. 人工核查结论

| 人工字段 | 分布 |
|---|---|
| RGB火焰可见性 | invisible 20/20（100%） |
| 烟遮挡程度 | heavy 20/20（100%） |
| IR是否更清晰 | yes 20/20（100%） |
| 是否小火点 | yes 4/20（20%），no 16/20（80%） |
| 备注 | “浓烟盖死,肉眼找不到”18/20；“浓烟盖死,图片全是烟”2/20 |

这组最差失败样本的主导现象是烟遮挡下RGB不可见，而不是小火点：只有4张被人工标为
小火点，但20张均被标为heavy烟遮挡、RGB不可见且IR更清晰。因此SAMF“烟概率门控的
热注入”比先做一般性边界增强或只针对小目标的模块更直接对应当前病因。

因此“低亮度”不足以解释这些失败，Smoke邻近/遮挡与人工结论更一致。

## 4. 与全验证集机器证据互证

既有`summary.json`覆盖验证集240张，其中180张含Fire、共1,406,630个Fire像素：

- 全验证集Fire像素处于5像素Smoke GT邻域的比例为`0.598542`；
- worst-20逐图Smoke邻域比例均值为`0.864966`、中位数`0.882733`；
- 三分类GT互斥，所以exact Fire/Smoke overlap必然为0。Smoke proximity只能称为
  邻近/遮挡代理，不能冒充真实同像素重叠。

人工20/20 heavy烟遮挡与机器Smoke邻域高比例方向一致。两类证据共同支持“RGB在烟幕
场景中的火焰可见性是主要瓶颈”，并确认SAMF优先级；这仍是动机与病因证据，不等价于
SAMF必然提升精度，后者必须由冻结协议的30轮与100轮实验验证。
