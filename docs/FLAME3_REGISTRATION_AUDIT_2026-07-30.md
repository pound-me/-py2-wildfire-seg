# FLAME3 配准审计

本审计只读取原始数据，不修改 RGB 或热红外文件。

## 冻结判定规则

- 抽样覆盖 Fire 与 No Fire，并按文件序列均匀取样。
- 使用 RGB/热红外梯度图进行仿射 ECC 估计；超出预注册范围的变换判为不可信。
- 只有样本数充足、偏移方向稳定、离散度低、偏移达到实质幅度且相似度有稳定提升时，数值规则才推荐全局仿射。
- 即使数值规则推荐，也必须人工检查全部叠图后才能启用；禁止逐图用验证结果拟合变换。

## 自动结果

- 样本数：30，类别分布：{'Fire': 15, 'No Fire': 15}。
- 置信度分布：{'usable': 18, 'low_gain': 1, 'implausible': 11, 'failed': 0}。
- 数值规则是否推荐全局仿射：`False`。
- 候选全局参数（仅供人工复核）：`{'dx_px': 7.749655246734619, 'dy_px': 2.2058626413345337, 'rotation_deg': -0.6147868042742556, 'scale_x': 0.9738784258589338, 'scale_y': 0.9985998325901103}`。
- 可用估计样本的残余偏移中位数为 `dx=7.750 px`、`dy=2.206 px`，但
  MAD 分别达到 `3.373 px`、`1.797 px`，超过预注册稳定阈值 `1.5 px`。
- 旋转 MAD 为 `0.234°`，尺度 MAD 为 `0.0103/0.0061`，同样超过稳定阈值。
- 30 张叠图人工复核显示：官方 Corrected FOV 已完成大体视场对齐，但
  火场烟雾遮挡、热响应与可见光纹理差异使自动仿射估计呈明显样本依赖；
  不存在证据支持一组固定仿射参数覆盖全部样本。
- 最终应用状态：`global_affine_not_applied`。

## 决策

保留官方 `RGB/Corrected FOV` 与 `Thermal/Celsius TIFF` 原始配对，不对源文件
或训练输入施加全局仿射。后续温度伪标签与热红外严格同坐标生成；RGB-T
残余错位作为数据局限记录，并在零样本错误画像中单独观察。若未来取得多场次
完整版，只重新执行同一冻结审计，不回看模型结果调配准参数。

详细数值见 `registration_metrics.csv` 和 `registration_summary.json`，
人工检查图见 `registration_contact_sheet.jpg` 与 `visuals/`。
