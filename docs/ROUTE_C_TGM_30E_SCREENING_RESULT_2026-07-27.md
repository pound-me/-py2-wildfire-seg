# Route C TGM 30轮筛选与组合触发结果

日期：2026-07-27

结论：TGM未通过自身30轮晋级门槛，也未满足Amendment 5的“正向TGM”触发条件。因此不跑TGM 100轮，不启动ABL+SAMF或ABL+SAMF+TGM组合实验。

## 1. 运行完整性

- 运行：`route_c_pidnet_s_tgm/route_c_tgm_30e_label_fix_seed200`；
- seed 200，RTX 2060，AMP，100轮学习率horizon；
- ImageNet预训练匹配301个张量；
- 完成30/30轮，stderr为空，测试集未使用；
- 用时985.4秒，峰值分配显存245.3 MB。

## 2. 第26–30轮窗口

| 指标 | Fusion基线 | TGM | 变化 |
|---|---:|---:|---:|
| mIoU均值 | 0.786141 | 0.783063 | -0.003078 |
| Smoke IoU均值 | 0.819727 | 0.816538 | -0.003189 |
| Fire IoU均值 | 0.646710 | 0.640564 | -0.006146 |

Fire变化仍在Fusion保守噪声带`±0.014251`内，但mIoU与Fire增益均为负。无Smoke/Fire类别崩溃。

TGM自身规则要求mIoU至少`+0.005`，或Fire超过保守噪声带且mIoU降幅不超过`0.005`。两条均未满足，所以不进入100轮。

## 3. Amendment 5组合触发判定

预注册正向条件要求mIoU或Fire至少一项严格正增益，另一项保持在原容忍范围，同时无类别崩溃并达到30 FPS。TGM虽然满足容忍范围、无崩溃且达到44.78 FPS，但mIoU与Fire均未严格为正，因此触发失败：

- `ABL+SAMF`：不授权30轮；
- `ABL+SAMF+TGM`：不授权30轮。

这不是主观取消组合，而是执行在TGM结果产生前已提交的条件规则。
