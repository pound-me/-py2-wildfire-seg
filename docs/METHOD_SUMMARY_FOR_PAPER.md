## 2. 损失函数(共 5 项求和)

```
L_total = L_lovasz(主输出) + L_lovasz(辅助头)      # 语义,直接优化IoU,类别权重[2.28,3.04,8.87]
        + 20 × L_bce(边界头)                       # D支路边界监督,加权BCE
        + L_ohem(边界区域语义)                     # 预测边界像素上的难例交叉熵
        + λ × L_ABL                                # 本文加入,主攻烟雾模糊边缘
```

实现:`third_party/RoboFireFuseNet/utils/total_loss.py`(前四项)+ ABL 集成(route 配置)。

## 3. 结构示意(正式图用 draw.io 重绘)

```
 RGB(3ch) ─┐
           ├─→ 4通道拼接 ─→ 共享干 ─┬─→ P支路(高分辨率·细节) ──┐
 IR(1ch) ──┤                       ├─→ I支路(下采样·语义)─→ DAPPM ─→ Pag融合(I→P)
           │                       └─→ D支路(边界预测) ────────┘        │
           │  ★SAMF(本文) ─────────────────────────────────────────────┤
           └─→ ThermalStem → 热特征T                                   │
               辅助头(注入前特征) → 烟概率图G                           │
               注入: F_out = F_in + β·G ⊙ ψ(T)  (β零初始化)            │
                                                                       ▼
                                              Bag最终融合(P+I+D,边界引导)
                                                                       ▼
                                                     分割头 → 背景/烟/火
 训练期专属:ABL 及其余 4 项损失(推理时消失)
```

## 5. 贡献的模块式写法(供引言 contributions 段选用)

1. 提出 SAMF:以网络自身的烟概率预测为空间门,在烟遮挡区域定向注入红外特征,
   零初始化残差保证不劣于基线,推理开销约 2.6 FPS;
2. 构建输入级(RGB+IR)/损失级(ABL)/结构级(SAMF)三层面的非对称模态处理方案,
   3-seed 预注册判据显著且保持 43.75 FPS 实时;
3. 提供输入模态不对称的实证分析(Table 1)与六种通用轻量模块的系统性阴性对照,
   并量化数据集噪声地板(mIoU ±0.0007)。
